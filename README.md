Pruebas realizadas

•	main — Rama principal e integración final.

•	backend — Desarrollo de JavaScript.
•	test-doc — Documentación y pruebas.

Durante el desarrollo se utilizaron comandos de Git para:
Clonar el repositorio.
Crear y utilizar ramas.
Realizar commits.
Subir cambios mediante push.
Actualizar el repositorio mediante pull.
Integrar las ramas mediante merge.
